# 3reelicious — Modern Dining & Pure Vegetarian Kitchen

A modern, responsive web application for **3reelicious** restaurant located in Civil Lines, Bareilly, Uttar Pradesh. Featuring an artisan pure-vegetarian menu, handcrafted stone-baked sourdough pizzas, traditional tandoori delicacies, and signature South Indian & Chinese dishes.

---

## 🍽️ Key Features

- **Artisan Home Showcase**: Hero section, chef highlights, and culinary story.
- **Itemised Digital Menu (`/menu`)**:
  - Clean tabular format displaying Item Name and Price (₹).
  - Categorized pill navigation across 13+ culinary sections.
  - Live search bar and filter toggles (Bestsellers, Spicy Only).
  - Fully mobile-responsive layout with floating scroll-to-top button.
- **Our Story & Moments Gallery (`/about`)**:
  - Founder's journey, 4 core values, and executive culinary leadership.
  - Responsive visual moments gallery featuring dining spaces, signature pav bhaji, tandoori missi roti, and plated specialties.
- **Contact & Directions (`/contact`)**:
  - Direct click-to-call and click-to-chat WhatsApp concierge (`+91 83938 33933`).
  - Google Maps direct launcher for Number 12, Civil Lines, Bareilly.
  - Event buyout and catering inquiry form with interactive FAQ accordion.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: Base UI + custom polymorphic button primitives
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

```bash
npm run build
npm run start
```
